# 提案: 手数カーブの既定値変更と既定 on 化を doc に反映する

user 判断「これ以上調査すると時間がかかりすぎるので，いったんこれで
デフォルトにする」．

## VETO との関係 (明記して残す)

VETO「レバーは『より強い』を A/B で確認してから既定化」に対し，本件は
**t = +1.15 / CI [−47, +262] で有意水準に達していない**状態での既定化．
user が費用対効果を踏まえて判断したもので，**確認済みではない**．

将来のセッションが「確認済み」と誤読しないよう，doc とコード doc コメント
の両方に **CI が 0 を含むこと**と**追試に 60 局要ること**を明記する．
覆ったら `curve_enabled` を false に戻すだけで済む (reversibility: easy)．

## 変更内容

`TimeCurve::MIDGAME` → `TimeCurve::DEFAULT` に改名 (山の位置が中盤でなく
なったため名前が実態と食い違う) し，値を差し替えた:

| | 旧 (失敗) | 新 (既定) |
|---|---|---|
| peak_ply | 55 | **100** |
| half_width_ply | 35 | **55** |
| peak_permille | 1800 | **2500** |
| opening_floor_permille | 700 | **300** |
| endgame_floor_permille | 1000 | **1200** |
| curve_enabled | false | **true** |

## 測定の要約

| 設定 | n | A スコア | Elo | paired t |
|---|---|---|---|---|
| 山=中盤 | 40 | 33.8% | −117 | −2.37 |
| 山=中盤 (再現) | 10 | 35.0% | −108 | −1.50 |
| **山=変換期** | **20** | **65.0%** | **+108** | **+1.15** |

符号の反転は 2 系列で一貫 (約 220 Elo の開き)．変換期版が一律配分より
強いことは未確定．

## 何が分かって設計が変わったか

1. **序盤の探索時間はほぼ無価値** — 中立な再解析で ply 9-30 の平均
   winrate loss が 0.0004 (相手 0.0013)．削る原資にしてよい．
2. **変換期の時間は中盤より価値が高い** — 中盤 +12% が loss を Δ0.0022
   しか改善しないのに対し，変換期 −10% は Δ0.0077 悪化させた．
3. **「終盤の底を 1.0 にすれば終盤は守られる」は誤りだった** — 同じ乗数
   でも掛ける先のバンクが中盤で減っていれば絶対量は減る．最初の形は
   ply 91-110 が B の 0.90 倍まで痩せ，勝勢からの逆転負けがその帯に
   集中した．終盤側の底は一律より**上** (1.2) に置く必要がある．
4. **実効ピークは `peak_ply` より手前**に来る (重みが上がる一方で残り時間が
   減るため積が先に頂点を迎える)．
5. **フィッシャーでは増加分がカーブを薄める** — 300+10 では公称 0.3〜2.5
   倍が実効 0.75〜1.25 倍にしかならない．

## 提案する doc 変更

1. `docs/commands/usi.md` / `floodgate.md` / `selfplay.md`: CLI 表と
   `setoption` 表の既定値を新値へ．「既定 on だが CI は 0 を含む」を明記．
2. `docs/design/usi-engine/index.md` §8.1.1: カーブの説明を変換期版へ
   書き換え，**中盤版がなぜ失敗したか** (上記 3) を残す．
3. `docs/design/usi-engine/verification.md` §4.4.1: 3 系列の測定結果，
   発火量の予測 vs 実測，中立再解析の所見，追試手順，未決 (追試 40 局 /
   さらに寄せる用量 / 長手数化と 512 手ルール / 詰まされる側の盲点)．

## 未決 (次セッション)
